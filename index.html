Priority Algorithm & Urgency Formula

How CampusCare mathematically ranks unresolved complaints
The Mathematical Urgency Formula:
Urgency Score = Category Weight + ⌊Hours Pending / 24⌋
Where ⌊x⌋ is the floor function taking the greatest integer ≤ x.

1. Category Weights

Laboratory3

2. Tie-Breaking Hierarchy

  1. Highest urgency score first (descending order).
  2. Older complaint first if scores are equal (larger hours pending).
  3. Smaller Complaint ID first if both score and age are equal (lexicographical).
Strict Requirement: Resolved complaints are immediately excluded from the priority queue, regardless of their mathematical score.

Presentation & Q&A Guide

Quick cheat-sheet for Campus Complaint Management System Evaluation

Q1. What problem does your project solve?

CampusCare provides a centralized, transparent platform where students report issues and campus administration can monitor progress, manage ticket lifecycles, and prioritize high-urgency unresolved complaints automatically using a mathematical queue.

Q2. How does the priority algorithm work?

We calculate an urgency score using: Urgency Score = Category Weight + floor(Hours Pending / 24). Category weights reflect operational impact (Laboratory=3, Wi-Fi=2, Hostel=2, Classroom=1). Every additional 24 hours of unresolved pendency adds +1 urgency point. Tied complaints are sorted by oldest age first, then lexicographically by Complaint ID.

Q3. What happens when a complaint is marked Resolved?

Its status changes to Resolved, the resolution timestamp is recorded, the summary counters update, and it is strictly purged from the Top 3 Priority Queue as required by the specification.

Q4. Why did you choose Vanilla JS with LocalStorage?

It eliminates heavyweight runtime overhead and external database dependencies while providing persistent state across page reloads. It delivers instant, zero-latency rendering and allows any judge to inspect the data structures in browser dev tools.
